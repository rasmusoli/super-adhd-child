# Changelog

## 1.4.0 - 2026-08-03

- Replaced unconditional delegation-on-activation with economics-based routing
  that chooses the cheapest sufficient topology and keeps trivial or tightly
  coupled work direct.
- Added compact Reader, Builder, review, parallelism, and full-SDD routing
  guidance without weakening high-assurance review gates.
- Added capability-aware event waiting, bounded file handoffs, and a relevant
  documentation-consistency preflight that resolves material contradictions at
  coordinator level.
- Preserved manual-first ADHD ideation and regenerated the deterministic plugin
  archive.

## 1.3.0 - 2026-08-02

- Removed five excluded debugging development files and made inventory
  exclusions machine-enforced in validation, drift checks, and packaging.
- Consolidated Codex collaboration guidance into the universal bootstrap and
  removed the redundant Codex reference-file lookup.
- Reduced the default ADHD run to five divergent roles plus three deepening
  roles, with scoring, trap detection, clustering, ranking, and selection done
  inline by the orchestrator.
- Removed references to skills not shipped by this plugin and shortened
  dispatch-skill hot paths while preserving their review and verification
  gates.

## 1.2.0 - 2026-08-01

- Clarified manual-first ADHD routing and the portable explicit invocation.
- Made isolated-subagent, concurrency, lifecycle, model, timing, and cost
  guidance capability- and policy-aware.
- Added dependency-free repository validation, deterministic archive packaging,
  fixture-driven tests, upstream inventory, and read-only drift checks.
- Kept the skills-only runtime boundary, pinned attribution, namespace
  adaptation, and committed `skill.zip` artifact intact.
